# AlphaDevelopmental.github.io

Personal portfolio site for **AlphaDevelopmental Technologies** — Taiwo Micheal Glass.

Cybersecurity & DevOps Engineer · Application Security Specialist · Product Engineer

🔗 Live site: https://alphadevelopmental.github.io

## Stack

- HTML5 / modern CSS3 (custom properties, Grid, Flexbox)
- Vanilla JavaScript (ES6+) — no build step, no framework
- [Web3Forms](https://web3forms.com) for the contact form

## Structure

```
index.html   → page structure and content
style.css    → design system (cyber-glassmorphism theme)
script.js    → terminal, command palette (⌘K), filters, scroll effects, contact form
assets/      → logo and favicon files
```

## Features

- Interactive terminal with command interpreter (`help`, `skills`, `projects`, `contact`, `whoami`)
- Command palette (Ctrl/Cmd + K) for quick navigation
- Filterable project grid (Product Eng / AppSec / DevOps / AI Systems)
- Scroll-triggered reveal animations and active-section nav highlighting

## Deploy

This repo is served directly by GitHub Pages from the `main` branch — any commit here updates the live site automatically.
