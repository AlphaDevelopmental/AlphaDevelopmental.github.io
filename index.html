    01 / about

    About me

    Ajani Taiwo Micheal is a Nigerian cybersecurity researcher, technology entrepreneur and educator whose work spans application security, offensive security, secure software engineering, emerging artificial intelligence security and practical technology education.

    He is the Founder of AlphaDevelopmental, comprising AlphaDevelopmental Technologies and AlphaDevelopmental Academy, and works as a cybersecurity instructor and curriculum developer at SQI College of ICT, Ibadan, where he develops hands-on security training, technical laboratories and competency-based learning experiences.

    His technical interests include web and API security, penetration testing, DevSecOps, network security, AI red-teaming, adversarial testing and large language model security. He is passionate about bridging academic learning and practical industry competence, strengthening Africa’s cybersecurity workforce and advancing secure technological innovation.

    02 / research

    Research interests & outputs

    Applied, reproducible security research — investigating how real systems fail and turning the findings into tooling, laboratories and curriculum.

    • R1

      Web & API security

      Vulnerability classes in modern web applications and APIs, studied through reproducible attack-and-defence labs.

    • R2

      Authentication & authorisation weaknesses

      IDOR, privilege escalation, session and cookie flaws, and the gap between authentication, authorisation and ownership.

    • R3

      CORS & Same-Origin Policy

      Misconfiguration classes such as credentialed origin reflection, null-origin trust and regex bypasses.

    • R4

      JWT security

      Signature-validation gaps, algorithm confusion, weak secrets and safe token-handling patterns.

    • R5

      Security automation

      Scope-aware reconnaissance and triage tooling that records what it verified — and what it could not.

    • R6

      DevSecOps

      Blocking CI/CD security gates — secrets, SAST, SCA and container scanning — and the limits of scanner coverage.

    • R7

      AI security & adversarial testing

      Prompt injection, AI-agent tool abuse and the adversarial robustness of LLM-integrated web systems.

    • R8

      Cybersecurity education & workforce

      Competency-based curriculum and lab design that closes the gap between academic learning and industry practice.

    DevSecOpsComplete

    DevSecOps Security Gate Pipeline

    Vulnerable code, leaked credentials and outdated dependencies reaching deployment unchecked.

    My contribution
    Designed a four-gate GitHub Actions pipeline — Gitleaks, Semgrep SAST, Trivy SCA and container scanning — then seeded, detected and remediated real findings.
    Significance
    Hard, blocking gates with least-privilege tokens and SHA-pinned Actions; the full fail → remediate → pass run history is preserved as evidence.

    DevSecOpsComplete

    AppSec CI Guardrails

    Does a CI security-gate design generalise beyond the codebase it was built for?

    My contribution
    Replicated the four-gate architecture on a multi-route Flask target seeded with CWE-89, CWE-78, CWE-502, CWE-215, CWE-22 and CWE-798 flaws; remediated and re-verified each.
    Significance
    Documents a scanner blind spot: the seeded path traversal was not detected by the SAST rulesets used — a passing scan is not proof of safety.
    • Python
    • Semgrep
    • Trivy
    • Docker
